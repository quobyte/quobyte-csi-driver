# Quobyte CSI

Quobyte CSI is the implementation of
 [Container Storage Interface (CSI)](https://github.com/container-storage-interface/spec/tree/release-1.0).
 Quobyte CSI enables easy integration of Quobyte Storage into Kubernetes.

For installation and examples, please refer to [Quobyte K8S resources](https://github.com/quobyte/quobyte-k8s-resources)
